# 🩸 Blood Bank Management System

A comprehensive **Blood Bank Management System** developed using **Python**, **Tkinter**, and **SQLite**. This desktop application streamlines the management of blood donors, patients, blood inventory, and reports through an intuitive graphical user interface.

The project was created to strengthen Python programming skills while implementing real-world database management, GUI development, and data handling concepts.

---

# ✨ Features

- 🩸 **Donor Management**
  - Add, update, delete, and view donor records.
  - Store donor details including blood group, contact information, and address.

- 🏥 **Patient Management**
  - Maintain patient information.
  - Record blood requirements and allocations.

- 📊 **Reports Dashboard**
  - Generate detailed reports.
  - View donor and patient statistics.

- 🔍 **Advanced Search & Filter**
  - Search records by name, blood group, city, and other fields.
  - Quickly locate required information.

- ✅ **Data Validation**
  - Prevent incomplete or invalid data entry.
  - Ensure required fields are filled before saving records.

- 📤 **CSV Export**
  - Export filtered records to CSV format.
  - Simplifies reporting and data sharing.

- 🖥️ **User-Friendly Interface**
  - Multi-tab layout for easy navigation.
  - Clean and responsive desktop interface built with Tkinter.

# 🚀 Installation

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/Blood-Bank-Management-System.git

cd Blood-Bank-Management-System
```

---

## 2. Install Dependencies

```bash
pip install -r requirements.txt
```

> If no `requirements.txt` file is available, simply ensure Python 3.x is installed since the project primarily uses built-in libraries.

---

## 3. Run the Application

```bash
python main.py
```
