Blood Bank Management System
================================

A comprehensive blood bank management system was developed as a practice project for Python language skills.

Features:
Multi-tab UI: Separate tabs for managing donors, patients, and generating reports.
Data Validation: Ensures accurate data entry with required field checks and type validation.
Search/Filter Functionality: Efficient record management through search filters by name, blood group, and more.
CSV Export: Quick export of visible records to CSV for easy sharing or data analysis.
Technologies Used:
Python 3.x
SQLite (database)
Tkinter (GUI library)
Requirements:
Python 3.x is installed on your system
SQLite database software (comes bundled with most Python installations)
Basic understanding of Python and its syntax
Setup Instructions:
Clone the repository using git clone 
Install required packages by running pip install -r requirements.txt in your terminal/command prompt
Run the application with python main.py
